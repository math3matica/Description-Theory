# Description Theory Glossary

This glossary is an alphabetized reference for core terms in Description Theory (DT).

It is a support document, not the theory itself.
Definitions here are working definitions based on the current clarified discussion and can be refined as the manuscript develops.

## Background

The relative environment against which a foreground is described. In DT, the background is what allows the foreground to be distinguished. In many cases, the background can be expressed as `~x` relative to a described thing `(x)`.

## Codefinition

The idea that things are defined together through their contrasts rather than in isolation. A thing is what it is through what it is not, and this mutual structure of distinction is part of its definition.

## Complete Definition

In DT, a complete definition is not the naming of an inner essence. It is a full account of a thing through a sufficient system of contrast statements. A thing is completely defined by the relational structure of what it is and what it is not.

## Context

The formal DT term for what ordinary language calls a thing. A context is a structured set of contrasts. In DT, things and contexts are the same, though `context` is the more formal term.

## Contrast

The fundamental relation by which one thing is distinguished from what it is not. DT treats contrast as basic to description. The symbol `>` is used to indicate this relation.

## Description

A description is the indication of a thing relative to the environment against which it is distinguished. In DT, description has the form of contrast, such as `(x) > (~x)`.

## Description Theory (DT)

A theory that treats description as fundamentally contrastive and relational. DT aims to show that things can be defined through systems of contrast without requiring appeal to an independently self-grounding substance.

## Distinction

The act or structure of identifying one thing as different from another. In DT, distinction is not secondary to description; it is what makes description possible.

## Flow

A DT concept used to explain how some descriptions come into prominence within a field of possible contrasts. The current manuscript still needs sharper clarification on whether flow belongs in the smallest core of the theory or in a later extension.

## Foreground

What is being indicated or brought into focus in a description. The foreground is described in relation to a background and is written in notation such as `(foreground) > (background)`.

## Fundamental Substance

The idea that a thing must ultimately rest on some deeper self-existing essence or primitive substrate in order to be defined. DT challenges the need for this by arguing that relational definition may be sufficient.

## Infinite Description

The idea that any description can be decomposed into further sub-descriptions indefinitely. In DT, this means a thing can be understood as a recursively elaborated context of contrast statements.

## Notation

The symbolic form used in DT to express contrastive relations. Core notation includes `()`, `>`, and `~`.

## `()`

Parentheses are used to mark a thing, context, or named descriptive unit within DT notation, such as `(tree)` or `(door)`.

## `>`

The symbol for contrast in DT. It indicates the relation by which a foreground is described against a background. In the elaborated theory, `>` is not merely a notation choice but a representation of the underlying contrast relation itself.

## `~x`

The relevant non-`x` environment against which `(x)` is described. In DT, `~x` is not only abstract logical negation; it names the contextual field that makes the distinction of `(x)` possible.

## Pure Contrast

A statement of difference at the most reduced level of description. In working DT terms, a pure contrast statement has the form `(x) > (~x)` or its contextual equivalent. A thing can be understood as a system of such statements.

## Relational Definition

Definition achieved through relations of difference rather than through appeal to an isolated essence. This is central to DT's claim that a thing can be fully defined through what distinguishes it from what it is not.

## Starting Claim

The basic claim from which DT begins: anything can only be described by being distinguished from what it is not.

## Thing

The ordinary-language term for what DT formally calls a context. A thing is a context of contrasts and is not separate from that context.

## Ultimate Thesis

The larger conclusion DT aims to reach through its exposition: a complete definition can be achieved through relational definition alone, and this is more complete than merely asserting a fundamental existence that cannot itself be defined.
