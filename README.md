# Description-Theory

Documentation for the Description Theory project.

## Repository layout
- `Description Theory Index.md`: top-level reading order.
- `Description Theory Abstract.md`: project abstract.
- `Description Theory Chapter *.md`: primary chapter drafts.
- `archive/`: non-canonical or superseded draft material retained for reference.

## Current editing workflow
1. Keep one canonical chapter file per chapter number.
2. Move alternate drafts and experiments into `archive/`.
3. Use the index file as the authoritative reading sequence.
